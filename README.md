# Grade-Master
GradeMaster adalah aplikasi web untuk mengelola proses pascapanen kopi, mulai dari penerimaan setoran petani, penilaian mutu (grading), penetapan harga, hingga pengelolaan stok dan pesanan pembeli. Aplikasi dikembangkan dengan Scala 3 dan Cask, serta menerapkan prinsip Pemrograman Fungsional pada seluruh logika bisnisnya.

> [!NOTE]
> Project ini dibuat untuk penilaian matakuliah Pemrograman fungsional, semua source code disini hanyalah untuk pebelajaran.

## Cara menjalankan Project
```
git clone https://github.com/Firdausizm/functional_programing_project.git

cd project_pf

sbt fastLinkJS

python -m http.server 8000

```
